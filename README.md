# 妆搭 · 人脸采集与分析

依据《美妆穿搭App-功能清单与需求文档》V1.5 第 5.2 节，以及《妆搭-V1.5高保真原型》中的「03 人脸采集与分析」（P05 拍照取景、P06 面部分析报告）实现的手机网页版。

- 实时取景检测：光线、角度与表情、距离与位置、遮挡（刘海 / 口罩 / 眼镜）、多人脸。全部检查都通过后才能拍照。
- 相册上传：同样做质量检测，不合格不能进入分析。
- 面部分析：脸型（带匹配度）、三庭比例、眼、眉、鼻、唇、肤色冷暖与季型。每一项都附带测量依据，可以手动修改，化妆建议随修改实时更新。
- 照片管理：最多 5 张，可设默认试妆底图、重拍替换、删除（分析结果同步删除）、一键清除全部数据并撤回授权。
- 隐私：人脸信息单独授权；识别和分析都在手机本地完成；照片只存在本机浏览器（IndexedDB），不上传。

技术：原生 HTML / CSS / JS，无构建步骤。人脸关键点使用本地托管的 MediaPipe Face Landmarker（`vendor/mediapipe`，Apache-2.0），不依赖谷歌服务器。

本地预览：在本目录运行 `python3 -m http.server 8765`，然后打开 http://localhost:8765 。手机调用摄像头需要 https，可部署到 GitHub Pages。
